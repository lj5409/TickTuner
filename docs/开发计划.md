### 1.2 我建议补充的能力（不改变原需求，只是让它更好用）

**P0（第一版就做，成本低、收益高）**

13. 调音记录/稳定性评分、练习统计。

## 2. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 全屏高频闪烁诱发光敏不适 | 安全/体验 | 默认“柔和脉冲”；闪烁频率 >3 Hz 时弹提示并自动降级为颜色渐变；设置里可彻底关闭闪烁 |
| OLED 全屏纯白高亮发热、耗电 | 长时间使用烫手 | 默认用色块/边框而非全屏纯白；亮度上限提示；提供“低功耗模式”（只做小面积指示） |
| 闪光灯强度 API 厂商支持不一 | 强度滑块无效 | 启动时读 `FLASH_INFO_STRENGTH_MAXIMUM_LEVEL`；=0 或不支持则退化为开/关，滑块置灰并说明 |
| 闪光灯权限在部分 ROM 被额外校验 | 调用抛 `SecurityException` | 代码 try/catch；清单声明 `CAMERA` 但**按需**申请，仅在真的被拒时引导授权 |
| 节拍器抖动/音画不同步 | 练习体验差 | 音频线程按“采样数”调度，UI 从播放头反推拍点；提供 ±100 ms 音画校准 |
| 调音器低音弦（E1≈82 Hz）响应慢 | 调不准 | YIN 算法 + 自适应窗口（低音用 4096 点），置信度门限 + 中值平滑 |
| Vivo 后台省电策略杀进程 | 后台播放中断 | 第一版不做后台播放；前台持有 `FLAG_KEEP_SCREEN_ON`，音频焦点正常申请/释放 |
| APK 侧载被系统拦截 | 装不上 | 出 release 签名包；文档写明 OriginOS 的“允许安装未知来源/关闭安全检测”步骤 |
| 无网络权限被误认为功能缺失 | 用户疑惑 | 应用说明中明确“完全离线、不联网、无隐私采集” |

## 3. 技术方案

### 3.1 工程与依赖

- Kotlin 2.x + Jetpack Compose（BOM 最新稳定版）+ Material 3
- AGP 8.x / Gradle 8.x（Kotlin DSL + Version Catalog `libs.versions.toml`）
- `minSdk 26`（Android 8.0，覆盖 AAudio/自适应图标）、`targetSdk 36`、`compileSdk 36`
- JDK 21（AGP 8 要求 17+）
- 依赖尽量少：Compose、Lifecycle/ViewModel、DataStore、kotlinx-serialization。**不引入网络库、不申请 `INTERNET` 权限。**

单模块 `:app`，按功能分包（逻辑层保持纯 Kotlin，便于 JVM 单元测试）：

```
app/src/main/java/com/gtool/
├── MainActivity.kt
├── ui/                 # 主题、通用组件（表盘、指板、滑块）
├── feature/
│   ├── tuner/          # 调音器页面 + ViewModel
│   ├── metronome/      # 节拍器页面 + ViewModel
│   └── chords/         # 和弦页面 + ViewModel
├── core/
│   ├── music/          # Note、Tuning、Chord、VoicingGenerator（纯 Kotlin）
│   ├── audio/          # AudioEngine、ClickSynth、GuitarSynth、PitchDetector
│   ├── device/         # TorchController、ScreenFlashController、VibratorController
│   └── data/           # DataStore 仓库、序列化模型
└── settings/           # 全局设置页
```

### 3.2 音频引擎（三个功能共用一套）

- 48 kHz、PCM Float、单 `AudioTrack`（`MODE_STREAM` + `PERFORMANCE_MODE_LOW_LATENCY`），缓冲区约 2× 最小值。
- 独立高优先级线程做混音，**时钟以已写入采样数为准**，所有节拍/拨弦事件按采样点调度（误差 <1 ms）。
- 音源：
  - 节拍器：预渲染的短促 click（正弦+噪声瞬态，重音/弱音两种），几 KB。
  - 吉他：Karplus-Strong 物理建模，每个 MIDI 音预渲染并缓存，加低通与琴体 EQ，支持力度与拨弦位置差异。
- 音频焦点：播放时申请 `AUDIOFOCUS_GAIN_TRANSIENT`，来电/其他 App 播放时自动暂停并恢复。
- 音画同步：UI 用 `Choreographer` 读取播放头位置，计算当前拍点相位，避免“音频先行、动画滞后”。

### 3.3 调音器

- `AudioRecord`：48 kHz 单声道 PCM16，优先 `UNPROCESSED`，回退 `VOICE_RECOGNITION`。
- 音高检测：**YIN**（差分函数 + 累积均值归一化 + 抛物线插值），窗口 2048/4096 自适应；置信度 < 阈值时显示“—”。
- 计算：`midi = 69 + 12·log2(f/440×440/A4ref)`；音分偏差 `1200·log2(f/f_target)`。
- 显示：大号音名 + 八度、频率（1 位小数）、音分（±50 刻度表盘，±5 绿色区）、目标弦高亮；稳定在 ±3 音分 300 ms → 变绿 + 轻振动。
- 调弦管理：内置 8 套预设 + 用户自定义（名称、每弦音名/八度、排序），DataStore 持久化。
- 参考音：点击弦号播放 2 秒标准音（正弦 + 轻微衰减）。

### 3.4 节拍器

- 参数：BPM 30–300、拍号 2/4·3/4·4/4·6/8（可扩展）、细分 1–4、重音位置。
- 调度：提前 200 ms 生成 click 事件写入混音队列，拍点由采样时钟驱动。
- 静音模式三选一（可组合）：屏幕 / 闪光灯 / 振动；音频可单独开关。
  - 屏幕：全屏 `Compose` 覆盖层，每拍做颜色、亮度、缩放脉冲；`window.attributes.screenBrightness` 调亮度（无需系统权限）；颜色用 HSV 取色器 + 6 个预设。
  - 闪光灯：`CameraManager.setTorchMode` / `turnOnTorchWithStrengthLevel`（API 33+），强度 1..maxLevel；不支持强度则只做开关；脉冲宽度 40–60 ms，避免连续点亮过热。
  - 振动：`VibrationEffect.createOneShot`，强度可调。
- 视觉刷新：`Choreographer` 每帧计算相位，即使 120 Hz LTPO 也流畅；屏幕常亮。
- 校准：音画偏移 ±100 ms 滑杆（保存在设置里）。

### 3.5 和弦引擎

**和弦类型（第一版 18 种）**

| 类型 | 公式（半音） | 类型 | 公式 |
|---|---|---|---|
| 大三 maj | 0 4 7 | 小三 min | 0 3 7 |
| 属七 7 | 0 4 7 10 | 大七 maj7 | 0 4 7 11 |
| 小七 m7 | 0 3 7 10 | 半减 m7♭5 | 0 3 6 10 |
| 减 dim | 0 3 6 | 减七 dim7 | 0 3 6 9 |
| 增 aug | 0 4 8 | 挂二 sus2 | 0 2 7 |
| 挂四 sus4 | 0 5 7 | 六 6 | 0 4 7 9 |
| 小六 m6 | 0 3 7 9 | 加九 add9 | 0 4 7 14 |
| 九 9 | 0 4 7 10 14 | 大九 maj9 | 0 4 7 11 14 |
| 小九 m9 | 0 3 7 10 14 | 五度 power 5 | 0 7 |

**显示**

- 组成音卡片：音名（C/E/G）、音级（1/3/5）、频率（Hz）、和弦公式。
- 指板：6 弦 × 15 品，横向吉他视角（6 弦在下方）；根音红色实心、和弦音蓝色、非和弦音淡灰、空弦/闷音标记。
- 指法图：自动生成 3–5 个可弹把位，标手指编号与横按。

**指法生成算法**

1. 在 0–12 品窗口内枚举每弦品位 {-1 闷音, 0 空弦, 1..12}，剪枝：跨品 ≤4、发声弦 ≥4、必须含根音。
2. 打分：低音为根音（加分）、含完整三音（加分）、空弦多（加分）、把位低（加分）、避免内弦闷音（加分）、音域合理。
3. 取 Top 5，去重（相同品位组合），缓存 `(root, type, tuning, capo)` 结果。

**播放**

- 扫弦：每弦间隔 25–40 ms（下扫低→高，上扫反向），力度随机 ±10%。
- 分解：预设节奏型（如 6-3-2-1-2-3），速度 60–120 BPM，可循环。
- 动画：每次拨弦回调 `(stringIndex, timestamp)`，指板对应弦做 150 ms 的拨动/涟漪高亮；由于事件由音频线程按采样点发出，音画偏差 <20 ms。

### 3.7 数据模型（草案）

```kotlin

    val accentPattern: List<Int> = listOf(3, 1, 1, 1),
    val soundEnabled: Boolean = true, val screenEnabled: Boolean = false,
```

存储：`DataStore<Preferences>` + `kotlinx.serialization` 存 JSON 列表（调弦、预设、设置）。数据量很小，无需数据库。

出包流程：

1. `gradle :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`（自测用）
2. `keytool` 生成 `gtool-release.jks`，写 `keystore.properties`（已加入 `.gitignore`）
3. `gradle :app:assembleRelease` → `app/build/outputs/apk/release/app-release.apk`
4. `apksigner verify --print-certs` 校验；`adb install -r` 或拷贝到手机侧载

安装到手机：USB 打开开发者选项 → USB 调试 → `adb install -r app-release.apk`；或把 APK 传到手机，在 OriginOS 里允许“安装未知应用”。

## 6. 测试计划

- **真机为主**（模拟器无法测麦克风、闪光灯、真实亮度）：X300 Pro 上逐项走验收清单。
- **精度对比**：用手机调音器 vs 参考音源（如标准音叉/钢琴 App），记录音分偏差；低音弦单独测。
- **节拍稳定性**：录屏 + 音频回录，测 100 拍累计漂移（目标 <10 ms）。
- **闪光灯**：0/50/100% 强度目视对比；连续 10 分钟脉冲后测温度与是否降档。
- **和弦正确性**：脚本生成 216 个和弦的所有指法，人工抽查 30 个常用和弦；用 MIDI 导出核对音高。
- **兼容性**：Android 8/12/16 各一台（如有），重点测权限与闪光灯 API 分支。
