# GTool 架构约定（并行开发契约）

> 所有 subagent 必须先读本文件。只改自己名下的文件，不改共享文件，不新增依赖，不运行 Gradle（统一由主控构建）。

---

## 1. 包结构

```
com.gtool
├── MainActivity.kt / GtoolApplication.kt        # 共享，勿改
├── ui/GToolApp.kt, ui/theme/*                   # 共享，勿改
├── core/music/                                  # 共享模型 + VoicingGenerator（和弦模块负责）
├── core/data/                                   # 共享仓库，勿改
├── core/audio/                                  # 各功能自建音频类（按文件归属）
├── core/device/                                 # 节拍器负责
└── feature/{tuner,metronome,chords}/            # 各功能 UI + ViewModel
```

## 2. 共享 API（已实现，直接调用）

### 音高

```kotlin
PitchClass.of(semitone: Int): PitchClass
PitchClass.parse("C#"): PitchClass?
pc.sharpName / pc.flatName / pc.name(useFlats: Boolean) / pc.semitone
PitchClass.entries   // C..B 共 12 个

Note(pitchClass, octave)                 // 如 Note(PitchClass.E, 2)
Note.fromMidi(midi: Int): Note
Note.fromFrequency(hz: Double, a4: Double = 440.0): Note
Note.parse("E2"): Note?
note.midi / note.pitchClass / note.octave
note.frequency(a4: Double = 440.0): Double
note.name(useFlats: Boolean = false): String
centsFrom(frequency: Double, target: Double): Double   // 正 = 偏高
```

### 调弦

```kotlin
Tuning(id: String, name: String, strings: List<Note>, builtIn: Boolean = false)
// strings 顺序：低音弦 → 高音弦（吉他 6 弦 → 1 弦）
tuning.strings / tuning.name / tuning.id
tuning.joinedNames(useFlats)          // "E2 A2 D3 G3 B3 E4"
tuning.stringNumber(index)            // 0 -> 6

TuningLibrary.STANDARD / builtIns / all(custom) / find(id, custom) / blank(name)
```

### 和弦

```kotlin
Chord(root: PitchClass, quality: ChordQuality)
chord.tones: List<ChordTone>          // ChordTone(pitchClass, degree, semitone)
chord.displayName                     // "Cmaj7"
chord.notes(baseOctave: Int = 3): List<Note>
chord.contains(pitchClass)

ChordQuality.entries                  // 18 种
quality.id / displayName / symbol / intervals / degrees
```

### 指法

```kotlin
Voicing(frets: List<Int>, fingers: List<Int>, baseFret: Int, score: Int)
// frets: -1 闷音、0 空弦、>0 相对品位；顺序同 tuning.strings
```

## 3. UI 约定

- 三个入口 composable 由 `GToolApp` 直接调用，**签名固定**：`@Composable fun TunerScreen()`、`MetronomeScreen()`、`ChordsScreen()`，无参数。
- 底部导航由外层提供，页面内部不要再放 Scaffold 的 bottomBar；可用 `Column` + 滚动。
- 主题色从 `com.gtool.ui.theme` 引用：`Bg / Surface1 / Surface2 / Accent / InfoBlue / Warm / Danger / TextMain / TextMuted / RootRed / ChordBlue / FretWire`。
- 全局深色，字号偏大，触控目标 ≥48dp。
- 文案中文，直接写在 Kotlin 里（不新增 strings.xml 条目）。
- 状态用 `StateFlow` + `collectAsStateWithLifecycle()`；资源释放用 `DisposableEffect`。
- 不要新增第三方依赖（仅 Compose / lifecycle / datastore / kotlinx.coroutines / kotlinx.serialization）。
- 不要修改 `AndroidManifest.xml`（权限已齐全），不要改构建脚本。

## 5. 技术约束

- 音频采样率统一 48 kHz；`AudioTrack` 用 `MODE_STREAM` + `PERFORMANCE_MODE_LOW_LATENCY`（API 26+）。
- 音频线程不要做 Compose/主线程操作；回调用 `StateFlow` 或 `Channel`。
- 所有播放器必须提供 `release()`，在 `DisposableEffect` 的 `onDispose` 调用。
- 调音器麦克风：`AudioRecord`，`RECORD_AUDIO` 运行时权限（Compose `rememberLauncherForActivityResult`）。
- 闪光灯：先读 `CameraCharacteristics.FLASH_INFO_STRENGTH_MAXIMUM_LEVEL`，不支持强度则降级为开关；所有相机调用包 try/catch，失败回调 UI。
- 屏幕闪烁：用 Compose 覆盖层 + `window.attributes.screenBrightness`，不要改系统亮度。
- 不要在 `init` 里启动耗时任务；不要把大数组放 Compose state。

## 6. 构建与验证

- 主控负责运行 Gradle；subagent **不要**执行构建（会互相抢锁）。
- 可以用 `grep/read` 自查；纯逻辑模块请补 JVM 单元测试（`app/src/test/java/...`，JUnit4）。
- 完成后向主控报告：新增文件列表、公开 API、未验证/有风险的点。
