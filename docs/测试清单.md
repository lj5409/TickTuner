# GTool 真机测试清单（vivo X300 Pro）

> 每项测完打勾；失败项记录现象、机型/系统版本、复现步骤。
> 建议测试顺序：安装 → 权限 → 调音器 → 节拍器 → 和弦 → 压力/边界。

## 0. 安装与启动

- [ ] 拷贝 `app-release.apk` 到手机，允许「安装未知应用」后安装成功
- [ ] 桌面出现 GTool 图标（青绿圆环），名称正确
- [ ] 冷启动 <2 秒，无闪退
- [ ] 底部三个 Tab 可切换，切换不丢状态
- [ ] 深色主题正常，状态栏/导航栏不遮挡内容

## 1. 调音器

- [ ] 首次进入弹出麦克风权限；允许后开始工作
- [ ] 拒绝权限时显示说明与「去授权」，不崩溃
- [ ] 拨 6 弦空弦 E2，2 秒内显示 E2，偏差在 ±5 音分内可稳定
- [ ] 依次测 A2/D3/G3/B3/E4，音名正确
- [ ] 音准后变绿并显示「准」
- [ ] 表盘指针不剧烈抖动（平滑生效）
- [ ] 安静环境下不误报随机音
- [ ] 切换调弦（Drop D / 降半音 / DADGAD）后目标音正确
- [ ] 点弦号播放参考音，声音时长约 2 秒、无爆音
- [ ] A4 改 432/445 后读数随之变化
- [ ] 新增自定义调弦：改名、改 2 根弦、保存 → 列表出现
- [ ] 重启 App 后自定义调弦仍在
- [ ] 删除自定义调弦成功，内置调弦不可删
- [ ] 切到后台/锁屏后录音停止（状态栏麦克风图标消失）

## 2. 节拍器

### 基础
- [ ] 30 / 120 / 300 BPM 均可播放，速度听感正确
- [ ] 重音在每小节第 1 拍
- [ ] 拍号 2/4、3/4、4/4、6/8 与细分 1–4 正确
- [ ] Tap Tempo 连点 4 次得到接近的 BPM
- [ ] 拖动滑杆、点 +/− 都生效
- [ ] 退出页面自动停止，无残留声音

### 屏幕静音模式
- [ ] 关闭声音、开启屏幕后，每拍有颜色/亮度脉冲
- [ ] 颜色可改（预设 + 自定义），立即生效
- [ ] 亮度滑杆生效（1%–100%）
- [ ] pulse 与 flash 两种风格可辨
- [ ] >3 Hz 时出现安全提示且降级为柔和
- [ ] 运行中屏幕常亮
- [ ] 退出页面后窗口亮度恢复

### 闪光灯
- [ ] 开启后每拍闪光，与声音/画面同步
- [ ] 强度滑杆可调（若本机支持）
- [ ] 不支持强度时显示「本机不支持亮度调节」且仍能闪
- [ ] 快速切换开关不崩溃（相机占用/权限异常被捕获）

### 振动
- [ ] 开启后每拍振动，重音更强

### 校准
- [ ] 音画偏移 ±100ms 调整后，画面与声音对齐

## 3. 和弦

- [ ] 12 个根音都能选，和弦名正确（C、C#、Db…）
- [ ] 18 种类型都能选，组成音正确（如 Cmaj7 = C E G B）
- [ ] 音级标注正确（1 3 5 7 / b3 b5 …）
- [ ] 指板显示 6 弦 15 品，音位正确
- [ ] 根音红色且明显，和弦音蓝色，非和弦音淡灰
- [ ] C 大三至少给出 x32010 或 8-10-10-9-8-8 等常用指法
- [ ] 抽查 G、D、Am、F、B7、Cmaj7 指法可实际按下
- [ ] 指法图手指编号合理（横按 1 指）
- [ ] Capo 1–7 切换后指法整体平移，音名不变
- [ ] 扫弦（下/上）播放正常，逐弦有拨动动画
- [ ] 分解 53231323 播放正常，动画与声音同步
- [ ] 速度 60–120 生效，循环开关生效
- [ ] 播放中切换和弦/停止，无卡顿或叠音
- [ ] 退出页面自动停止并释放音频

## 4. 性能与边界

- [ ] 连续使用 20 分钟，机身温度正常、无掉帧
- [ ] 同时开屏幕闪烁 + 闪光灯 + 振动 5 分钟，无崩溃
- [ ] 连续快速切换和弦 100 次，指法生成不卡（<200ms/次）
- [ ] 系统字体放大到最大，布局不重叠
- [ ] 横竖屏切换（如允许）不崩溃
- [ ] 来电/其他 App 播放音频后，节拍器能恢复
- [ ] APK 体积：debug ≈12 MB，release 预计 6–8 MB
- [ ] 电池：20 分钟调音器耗电 <5%

## 6. v0.1.1 回归（5 个修复项）

- [ ] 调音器有声音/无声音切换时，弦位列表位置不跳
- [ ] 参考音音量：手机媒体音量 50% 时已能清楚听见低音 E2

- [ ] 和弦页切换到 Drop D / DADGAD / Open G，指板空弦音与各品音位正确

- [ ] 修改顺序后重启 App，顺序仍保留
