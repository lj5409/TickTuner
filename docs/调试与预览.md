# 预览与调试

> 目标：不装 Android Studio，也能看到真实渲染、点按交互、抓日志；需要 Compose Preview / 断点调试时再装 IDE。

## 1. 模拟器（已装好）

| 项 | 值 |
|---|---|
| AVD | `GTool_API36`（Pixel 9 参数，1080×2424，Android 16） |
| 镜像 | `system-images;android-36;default;x86_64`（AOSP，无需 Google 服务） |
| 加速 | WHPX（已确认可用） |
| AVD 目录 | `%USERPROFILE%\.android-dev\android-home\avd` |

### 常用命令

```powershell
pwsh scripts/emulator.ps1 -Action start            # 无窗口启动（截图/自动化）
pwsh scripts/emulator.ps1 -Action start -Windowed   # 带窗口，可直接看和点击
pwsh scripts/emulator.ps1 -Action install      # 安装 dist 下最新 APK
pwsh scripts/emulator.ps1 -Action launch       # 启动 App
pwsh scripts/emulator.ps1 -Action screenshot -Name tuner
pwsh scripts/emulator.ps1 -Action logcat       # 只看 App 进程日志
pwsh scripts/emulator.ps1 -Action tap -X 540 -Y 2250
pwsh scripts/emulator.ps1 -Action swipe -X 540 -Y 1800 -X2 540 -Y2 900
pwsh scripts/emulator.ps1 -Action status
pwsh scripts/emulator.ps1 -Action stop
```

截图会存到 `docs/screenshots/`。

### 手动 adb

```powershell
. "$env:USERPROFILE\.android-dev\bin\android-env.ps1"
adb devices
adb shell pm grant com.gtool android.permission.RECORD_AUDIO
adb shell am start -n com.gtool/.MainActivity
adb exec-out screencap -p > screen.png
```

### 查看布局层级（找控件坐标）

```powershell
adb shell uiautomator dump /sdcard/ui.xml
adb pull /sdcard/ui.xml
```

`ui.xml` 里有每个节点的 `bounds="[x1,y1][x2,y2]"`，可直接换算成 `input tap` 坐标。

## 2. 真机

手机开 USB 调试后：

```powershell
adb devices
adb install -r dist\GTool-0.2.1.apk
adb logcat --pid=$(adb shell pidof com.gtool)
```

想看手机屏幕到电脑、并用鼠标操作，可装 **scrcpy**（约 30 MB，无需 root）：

```powershell
winget install Genymobile.scrcpy
scrcpy --max-size 1280
```

## 3. 崩溃与日志

```powershell
# 只看崩溃
adb logcat -d -b crash

# 实时过滤
adb logcat --pid=$(adb shell pidof com.gtool)

# 清空后复现
adb logcat -c
```

## 4. Android Studio（可选）

需要 Compose Preview、Layout Inspector、断点调试时再装：

- 安装时把 SDK 路径指向 `C:\Users\Jon\.android-dev\sdk`，避免重复下载。
- 本项目 `debugImplementation("androidx.compose.ui:ui-tooling")` 已就绪，给 screen 加 `@Preview` 即可预览。
- Studio 自带 JBR，不影响命令行构建。

## 5. 已知限制

- 模拟器无 Google Play 服务；本 App 不依赖。
- 模拟器的麦克风/闪光灯行为与真机不同：调音器可能显示环境噪声，闪光灯不可用。
- 屏幕闪烁/亮度在模拟器上表现与 OLED 真机不同，最终以 X300 Pro 为准。
## 6. 其他项目复用

AVD、SDK、模拟器都安装在用户目录（`%USERPROFILE%\.android-dev`），**不绑定工作区**，任何项目都能共用同一套：

```powershell
. "$env:USERPROFILE\.android-dev\bin\android-env.ps1"
$emu = "$env:USERPROFILE\.android-dev\bin\emulator.ps1"

& $emu -Action list
& $emu -Action start -Avd GTool_API36
& $emu -Action install -Apk C:\path\to\app-debug.apk
& $emu -Action launch  -Package com.example.app
& $emu -Action screenshot -Name home -OutDir C:\temp
& $emu -Action logcat -Package com.example.app
& $emu -Action stop
```

说明：

- 多个项目可以装在同一台模拟器上，按包名隔离数据；同一时刻只有一个前台应用。
- 需要不同 Android 版本、Google Play 服务或平板形态时，再下载对应 system image 并新建 AVD（AVD 目录：`%USERPROFILE%\.android-dev\android-home\avd`）。
- 同一时间只运行一个 AVD；要并行测试可建多个 AVD，但每个约占 2–3 GB 内存。
- 本项目 `scripts/emulator.ps1` 是带 GTool 默认值的便捷版，通用版在 `%USERPROFILE%\.android-dev\bin\emulator.ps1`。
