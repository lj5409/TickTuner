### v0.5.0（2026-11-22）调音器多形态适配、调弦拖动排序与工程文档

- **调音器横屏专注模式**：横屏 / 帐篷模式下隐藏导航栏与设置，左侧自适应大调音表 + 右侧两列满屏 6 弦网格，全程无需滑动。
- **调音器折叠屏适配**：新增半折叠悬停模式（上大表盘 + 下双栏弦位与设置，避让水平折痕）与全展开双栏模式（左侧 `NavigationRail` + 左右双栏避让竖向折痕）。
- **调弦管理拖动排序**：内置与自定义调弦统一列表，按住左侧 6 点手柄上下拖动排序，持久化至 `AppSettings.tuningOrder` 并全局同步调音器与和弦页。
- **工程说明文档**：新增 `docs/工程说明.md` 与 `AGENTS.md`，规范后续交接与同步更新机制；新增 `TuningOrderTest`（总单测 52 项通过）。

### v0.4.0（2026-11-22）品牌更名与调音器精简

- 应用与仓库正式更名为 **TickTuner** 并启用新三角波形图标；调音器目标行精简至单行、收缩弦位高度、参考音升级为循环播放配停止按钮、弦位保留最后识别音分。

### v0.3.0 / v0.3.1（2026-11-22）节拍器重构与四态多形态适配

- 节拍器改版为方案 B 拉长药丸拍条、点击拍条舞台启停、内置 BPM 数字键盘（横屏双栏）、主拍闪屏、页面记忆，并接入 `WindowPosture` 完成直板/横屏/悬停/展开大屏四态适配。

### v0.2.1（2026-11-21）修复记录

- **节拍器静音模式**：修复 `ClickPlayer.audioLoop` 混音未判断 `soundEnabled` 导致静音模式下仍发声的问题，并在切静音时立即清空尾音缓冲。
- **和弦横按指法与手指编号**：修复 `VoicingGenerator.assignFingers` 中 `frets[i] <= minFret` 误拒标准大横按（恢复 F 大三 `1 3 3 2 1 1` 首选）及把高位多根弦重复标为同一手指的问题（F 大三为 `1 3 4 2 1 1`，Cm Capo 2 为 `× 1 3 4 2 1`）；过滤高位超过 3 弦的不可弹横按并惩罚跨空弦扭曲手型。
- **自定义调弦缓存失效**：`VoicingGenerator` 缓存 key 与 `ChordsViewModel.voicingKey` 纳入各弦 MIDI 音高，修改/删除自定义调弦时清理缓存并触发重算。
- **调音器八度防误判**：移除 `TunerViewModel` 的 `foldCents` 跨八度折叠，差一个八度不再显示绿色「准」，改为显示真实音分与「高过八度 / 低过八度」提示。
- **和弦播放与展示**：分解循环播放中修改拨弦顺序或切换预设立即生效；`ToneCard` 组成音频率跟随全局 `A4`；调弦栏自动滚动至选中项。
- **主题、并发与脚本**：`MainActivity` 使用 `SystemBarStyle.dark` 修复浅色系统模式下状态栏/导航栏对比度；统一节拍器 `FilterChip` 为青绿 `Accent`；加固 `ToneGenerator` / `AudioCapture` 释放并发安全；修复 `scripts/emulator.ps1` 冷启动等待空值异常；新增 4 项单测（总计 26 项）并清理全部 Kotlin Lint 警告。

### v0.2.0（2026-10-24）新功能

- 和弦模块新增调弦选择（内置 9 套 + 自定义），指板音位、组成音位置、推荐指法随调弦重算。
- 分解和弦支持自定义拨弦顺序：1–6 弦号、最多 16 步，默认 53231323，提供常用预设，350 ms 防抖持久化。
- 播放器 `ChordStyle.ARPEGGIO` 按自定义顺序调度，循环长度随顺序长度自适应。
- 新增 `ArpeggioPattern` 纯逻辑与 6 项单测（总测试数 22）。

### v0.1.1（2026-10-24）修复记录

- 节拍器拍点圆点：固定 40 dp 槽位 + `graphicsLayer` 缩放，缩放不再参与布局，强拍/弱拍切换不顶动下方 UI。
- 和弦 Capo：选项固定 48 dp 宽、说明文字 `minLines = 2`，0 与 1–7 切换不再跳动。
- 和弦播放中切 Capo：重新生成指法后按新指法自动续播；并修复 `stopPlayback()` 后状态被旧快照覆盖、按钮显示不同步的问题。
- 调音器：目标行固定 44 dp 高度并保留无信号时的占位，弦位列表不再上下跳。
- 调音器参考音：峰值 0.32 → 0.9，并叠加 2/3 次谐波，低音 E2 在小扬声器上明显更响。

### 未在真机验证的风险（来自各模块）

- **调音器**：AudioRecord 48k 无降级；UNPROCESSED/VOICE_RECOGNITION 厂商行为；置信度门限对真实吉他的表现；参考音无音频焦点。
- **节拍器**：`turnOnTorchWithStrengthLevel` 在 Vivo/OriginOS 的权限与亮度表现；闪光 40–60 ms 实际宽度；AudioTrack 200 ms 缓冲的启动偏差；窗口亮度脉冲可能被系统平滑。
- **和弦**：AudioTrack 实际延迟（理论音画 <30 ms）；Canvas 指板在 120 Hz 的性能；GuitarSynth PCM 缓存约 20–25 MB。
