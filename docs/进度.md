- **声学报告横屏全屏专注模式**：横屏时自动隐藏底部导航栏与非必要选项，满屏展示当前 FFT 频谱图，极简顶条支持下拉菜单或左右滑动切换敲击部位。

### v0.6.0（2026-11-22）新增吉他敲击 FFT 声学分析模块

- **新增第 4 顶层 Tab「声学」**：提供乐器建档（吉他名归类、形制、备注）、内置/外接 USB 指向麦热插拔选择、4 项物理测量准备清单与 5 点正/背板脉冲靶心引导图。
- **高精度离线 DSP 与质检引擎**：48 kHz 原始流采集 + 1 秒底噪校准 + 冲击测试非对称 Tukey 窗 + 65536 点零填充 FFT + 三点对数抛物线插值（0.1 Hz 精度）+ 半功率 Q / 窄带解析包络 Decay Q；自动拦截削波、二次连击、低 SNR、裸弦未消音与离群误敲，5 次一致敲击（$\gamma^2 \ge 0.90$）后推进（第 5 步可跳过，嘈杂环境支持人工确认兜底）。
- **声学报告、手动微调与离线导出**：解耦 $A_0/T_1/B_1/T_{2,1}/T_{1,2}$ 模态，自动排查狼音（精确定位低把位弦号/品位）、面背板反相相消与琴颈死点，给出五维加权评级、四大曲风适配度与保养建议；支持频谱图手动微调共振峰自动重算报告、高清 PNG 存相册/分享、原始 FFT 数值查表与 CSV/JSON 导出、以及离线 Markdown 与带内嵌高清频谱图的 A4 PDF 导出。
- **双记录横屏叠图对比**：支持同琴或跨琴任意 2 条记录同部位叠加对比，支持一键横屏全屏对比与折叠屏宽屏、切换叠放顺序（A 在上 ⇄ B 在上）、8 色曲线自选、0 dB 对齐 / 原始 dBFS 切换、共振峰差值对照与对比叠图 PNG 导出。
- **单测扩充**：新增 19 项单元测试（`FftEngineTest`、`TapCaptureProcessorTest`、`AcousticAnalyzerTest`、`AcousticReportFormatterTest` 及 4 Tab 路由测试），总单测 71 项全部通过。
